# Support

Report bugs and request help through [PlainSky's GitHub Issues page](https://github.com/ColumbusLabs/PlainSky/issues/new). GitHub issues are public, so do not include your precise location, home address, APNs device token, or other private information.

When reporting a problem, include the PlainSky version, iOS version, device model, what you expected to happen, and the steps that reproduce it. Remove personal details from screenshots and logs before posting.
